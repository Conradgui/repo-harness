# 决策记录（ADR）

每条记录一个**不可逆或代价高的决策**：当时的处境、考虑过的选项、选择的理由，以及后来被证明对不对。

不记录例行实现选择。判断标准：如果六个月后有人问"为什么当初不那样做"，答案不在代码里，就该有一条 ADR。

## 状态含义

- **已执行**：决策已落地，可在代码或 git 历史中验证
- **约束，长期生效**：这是一条持续适用的规则，不是一次性动作
- **已推翻**：后来的证据否定了它，记录保留并注明原因
